## 三、激化点(小投入 × 大价值)

- **G1 记忆化**(`→` P1):固定可持久化端口 + 服务端配对表落盘 + 客户端"已配对设备"记忆+自动重连。三件小事杀死最大日常摩擦,复用率直接翻倍。
- **G2 相册的脸**(`→` P2):/thumb token 端点 + 照片网格页。一个端点+一个页面,产品从"文件浏览器"变"相册浏览器"——这是立项文档定义的核心场景。
- **G3 正名**(`→` P3):删 spike 遗迹、入口升格。半小时的事,第一印象完全不同。
